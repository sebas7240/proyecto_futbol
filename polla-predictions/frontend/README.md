# Polla Predictions Frontend

Aplicacion React + Vite para consumir la API del MVP de predicciones.

## Inicio rapido

1. `npm install`
2. Configurar `.env`
3. `npm run dev`
4. Abrir `http://localhost:4173`

## Variables

```env
VITE_API_BASE=http://localhost:4000
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

## Funciones actuales

- Login con Google mediante Firebase Auth.
- Lista de partidos del backend.
- Panel de prediccion con mercados estructurados.
- Perfil con creditos, puntos y wallet Solana.
- Resultados experimentales.
- Historial de predicciones recientes.
